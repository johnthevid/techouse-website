# Self-hosted Techouse fonts

DM Sans and Manrope are the same variable WOFF2 files returned by the Google Fonts stylesheet used in Stable Build 1. All eight original subsets and weight range 300–800 are preserved. Latin files are preloaded; other subsets load only when needed.

SIL Open Font Licenses: `dmsans-OFL.txt` and `manrope-OFL.txt`, from the official google/fonts repository. File sources and SHA-256 hashes are recorded in `deployments/techouse-1.0/asset-manifest.json`.
